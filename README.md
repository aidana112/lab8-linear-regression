# ЛР 8. Линейная регрессия

Модель предсказывает месячную цену аренды квартиры в Астане. Данные взяты из 600 объявлений за август и сентябрь 2026 года. Модель учитывает район, площадь, число комнат, этаж, этажность дома, год постройки и наличие мебели.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # на Windows: .venv\Scripts\activate
pip install -r requirements.txt jupyter
python src/train.py                # пишет metrics.json и models/model.joblib
```

Исследование для шагов 2–9 лежит в `notebooks/lab8.ipynb`. Запускайте его целиком через Kernel, затем Restart & Run All.

## Отличия от методички

В выданном файле нет столбца `dist_center`. В шагах 6 и 12 вместо него берём год постройки `year`, поэтому параметр называется `year_bins`, а не `dist_bins`. В шаге 7 вместо него берём площадь `area`.

Служебные столбцы из ЛР 7 в модель не идут. Это `area_raw`, `area_nan`, `price_m2`, `floor_type` и `age_group`. Столбец `price_m2` равен `price / area`, то есть в нём уже есть ответ.

В `metrics.json` есть ещё `cv_rmse`, которой нет в методичке.

## Эксперименты

Эксперименты сравниваем только по `cv_r2`. Тест для выбора не используем.

| Эксперимент | Параметры | cv_r2 | cv_rmse | test_r2 | test_rmse | Решение |
|-------------|-----------|-------|---------|---------|-----------|---------|
| базовый | linear | 0.9162 | 27 096 | 0.9144 | 27 965 | текущая модель |
| bins-ridge | ridge, alpha=1.0, year_bins=8 | 0.9143 | 27 401 | 0.9121 | 28 340 | не принят, cv_r2 ниже |

Цена растёт с годом постройки почти по прямой. Средняя цена за м² поднимается примерно с 4 050 до 4 890 тг. Поэтому интервалы года ничего не дают, а 7 лишних весов только добавляют шум. Регуляризация тоже не нужна. На 450 объектах и 12–19 признаках модели почти не на чем переобучиться.

## Текущая модель

LinearRegression в Pipeline. Pipeline заполняет пропуски в числах медианой и стандартизирует числа. Пропуски в категориях он заполняет самым частым значением и кодирует категории через one-hot. Параметры лежат в `params.json`, метрики в `metrics.json`.

## Как пользоваться моделью

```python
import joblib, pandas as pd
model = joblib.load("models/model.joblib")
flat = pd.DataFrame([dict(rooms=2, area=60, floor=5, floors=12, year=2015,
                          district="Есиль", furniture="yes")])
print(round(model.predict(flat)[0]))   # 339711
```

Двухкомнатная квартира 60 м² в Есиле, дом 2015 года, с мебелью стоит около 340 тыс. тг в месяц. Если год и мебель неизвестны, Pipeline сам заполнит пропуски, и прогноз будет около 323 тыс. тг.
